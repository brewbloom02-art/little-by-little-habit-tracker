Install as Web App (PWA)

Works immediately on Android Chrome, Samsung Internet, and Safari. Launches full screen with offline support.

1
Open the website URL in Google Chrome on your Android device.
2
Tap the browser menu (⋮) in the top-right corner.
3
Tap "Add to Home screen" or "Install app".
4
Tap Add. Little by Little now appears on your home screen and drawer!

⚙️ Automated GitHub Actions Workflow Ready

The repository includes a ready-to-run GitHub Actions workflow (build-android-apk.yml) that compiles the Capacitor Android project into app-debug.apk.

View APK Builds in GitHub Actions

How to install the APK on your device:

1
Download app-debug.apk from the latest successful GitHub Actions workflow artifact or Release.
2
Open the downloaded APK on your Android device (via your notification or Files app).
3
If Android displays "For your security, your phone is not allowed to install unknown apps from this source", tap Settings and switch Allow from this source ON.
4
Tap Install, then tap Open to begin your calm daily routine.
